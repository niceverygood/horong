무기마다 기운이 하나씩 있어요. 나무(목) · 불(화) · 흙(토) · 쇠(금) · 물(수).

서로 살려 주는 순서가 있어요. 나무 → 불 → 흙 → 쇠 → 물 → 다시 나무. 이웃한 두 기운의 무기를 같이 들면 줄이 이어지고, 뒤쪽 무기는 피해 +15%, 앞쪽 무기는 더 자주 공격합니다. 셋 이상 이으면 두 배.

다섯 기운을 모두 모으면 20초마다 화면의 요괴를 한꺼번에 쓸어 버립니다.

이기는 기운도 있어요(그림 안쪽 빨간 화살표). 나무는 흙을, 흙은 물을, 물은 불을, 불은 쇠를, 쇠는 나무를 이겨 피해 +50%. 장터 요괴는 대부분 흙이라 나무 무기(도깨비 방망이)가 잘 듭니다.
