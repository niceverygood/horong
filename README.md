# 호롱: 백귀야행 — 웹 체험판

조선 밤길을 배경으로 한 서바이버류 게임의 웹 체험판입니다. 호롱불이 꺼지지 않게 기름을 주워 가며 요괴 행렬을 버팁니다. 공격은 자동이고 플레이어는 이동만 합니다.

- **1탄 · 밤 장터**: 9분에 깨어나는 이무기를 쓰러뜨리면 1탄이 끝납니다.
- **2탄 · 안개 산길**: 레벨·무기·패시브·엽전을 그대로 들고 이어집니다. 일반 요괴 6종(손각시·그림자귀·야광귀·저승새·망태 할아범·장승귀, 기술 3개씩), 보스 장산범(2:30) · 두억시니(5:00) · 불가살이(9:00). 불가살이를 쓰러뜨리면 승리입니다.

- 웹 체험판(claude.ai): https://claude.ai/artifact/2zdxPYtZDpU1kbE2hyrwY7
- 기획서: https://claude.ai/artifact/GFGoEUP9CcWNyiWRCeSZ9U

## 로컬에서 실행

`horong-demo/index.html` 은 페이지 조각(본문만)이라 `wrap.sh` 로 완성된 `test.html` 을 만든 뒤 띄웁니다.

```bash
bash wrap.sh
python3 -m http.server 8731 --directory horong-demo
```

브라우저에서 http://localhost:8731/test.html 을 엽니다. 주소 끝에 `#playground` 를 붙이면 바로 놀이터로 들어갑니다.

## 놀이터 (움직임 시험)

첫 화면의 **놀이터 · 움직임 시험** 버튼으로 들어갑니다. 시간이 흐르지 않고 요괴도 저절로 나오지 않습니다.

- 시간: 정지 · 0.1× ~ 2× · 한 프레임씩 넘기기 (키보드 `0` 정지/재개, `.` 한 프레임), 확대
- 등불지기: 연이/단비 전환, 이동 속도, 자동 걷기(원 · 8방향 · 좌우 · 위아래 · 멈췄다 걷기 · 지그재그), 보는 방향 · 걸음 위상 표시
- 무기: 6종 장착/해제, 레벨, 진화형 — 장착한 물건이 몸에 보이고 발동할 때 손에 들고 씁니다
- 요괴: 종류별 '화면 안/전체' 마릿수, 수량 조절(−/+·입력), 수량 유지, 종류별 쓰러뜨리기, 몹 기술 18개 하나씩 시키기, 포위진, 백귀야행
- 맵 요소: 8종을 바로 옆에 놓아 시험, 무대 전환(1탄 밤 장터 / 2탄 안개 산길)
- 무기 특성·패시브: 특성 전환, 패시브 8종 켜기/끄기와 레벨
- 보스: 그슨대 · 구미호 · 이무기 소환과 기술 하나씩 발동, 쓰러뜨리기
- 보물상자: 정예 · 보스 · 최종 상자를 바로 옆에 떨어뜨려 공개 연출 시험
- 금빛 도깨비: '무리' 줄의 버튼으로 바로 불러내기
- 설정: 무적, 요괴 안 죽음, 무기 발동, 보스 자동 공격, 몹 공격, 요괴 멈춤, 예측 위치 보기, 충돌 범위 보기, 환하게

## 게임 요소

- 맵 요소: 서낭당(기도하면 40초 축복) · 우물(회복) · 화톳불(빛 유지, 요괴 화상) · 돌탑(부수면 보상) · 도깨비 노름판(대박/본전/매복) · 보부상(엽전으로 구매) · 솟대(요괴 약화 결계) · 풍등(빛)
- 몹 기술: 일반 요괴 6종이 기술을 3개씩 쓰며(예고 표시 포함), 판이 진행될수록 차례로 풀립니다
- 무기 특성: 무기가 Lv 4가 되면 특성 둘 중 하나를 고릅니다(12종). 도깨비 방망이·먹물 붓도 진화형이 있습니다
- 패시브: 8종, 각자 능력치와 고유 효과(치명타, 막아냄, 밀쳐내기 등)를 함께 가집니다
- 오행 안내: 무기의 다섯 기운(나무·불·흙·쇠·물)을 그림으로 설명하는 화면(첫 화면 '오행이란?', HUD 오각형 누르기)

### 보상 연출 (도파민 보강 1차)

- 보물상자 복주머니 뽑기: 상자를 주우면 게임이 멈추고 1개 · 3개 · 5개 중 하나가 나옵니다. 상자 틈의 빛 색이 결과를 먼저 알려 주고(흰빛 → 푸른빛 → 금빛), 칸이 하나씩 멈춘 뒤 엽전(5 · 12 · 30냥)이 쏟아집니다. 확률은 정예 70/25/5%, 중간 보스 0/70/30%, 최종 보스는 5개 확정이며, 복주머니 패시브가 레벨마다 6%(1→3개)와 2%(3→5개)를 옮깁니다. 진화할 무기가 있으면 첫 칸이 진화입니다. 결과는 여는 순간 적용되고 공개는 보여 주기만 하므로, 누르면 바로 결과를 보고 한 번 더 누르면 닫힙니다(3초 뒤 자동으로 닫힘).
- 연참: 쉬지 않고 이어 잡은 수를 오른쪽에 크게 보여 줍니다. 처치 사이 허용 시간은 50까지 2초, 300까지 1초로 줄어듭니다(2초로 고정하면 적과 맞붙는 판에서 연참이 한 판 내내 끊기지 않았습니다). 50 빛 +5 · 100 엽전 비 · 250 신명(10초간 피해 +20%) · 500 지남철 · 1,000 보물상자. 처치 소리는 연참에 따라 높아집니다.
- 한꺼번에 N마리: 0.25초 안에 15마리 이상 쓰러뜨리면 외칩니다(2초에 한 번까지).
- 천 마리 퇴치: 한 판 처치 1,000마다 붉은 낙관이 찍히고 엽전 +10냥.
- 치명타: 모든 무기 공격에 5%(피해 2배, 붉은 인주는 레벨당 +5%). 치명타 숫자는 크게 튀고, 100 이상이면 '일격' 낙관이 붙습니다. 한 요괴에게 0.2초 안에 들어온 피해는 한 숫자로 합쳐 올라갑니다.
- 보스 체력 바는 깎인 만큼 흰 잔상이 0.4초 남았다가 줄어듭니다.
- 작은 손질: 경험치 바가 90%를 넘으면 숨 쉬듯 빛남, 레벨업 때 머리 위 'Lv N', 오행 원환 남은 시간 고리와 '오행 원환!' 컷인, 포위진을 뚫거나 70% 쓰러뜨리면 '포위 돌파!'(엽전 12냥), 백귀야행이 끝나면 처치·기름 집계, 노름판 윷가락 던지기, 큰 혼구슬(10 이상) 소리·빛.
### 보상 연출 (도파민 보강 2차)

- 금빛 도깨비: 1:00에 한 마리가 반드시 나오고, 그 뒤 2분마다 40% 확률로 나옵니다. 엽전을 흘리며 도망치고(너무 멀어지면 느려짐), 맞을 때마다 엽전이 튀며, 15초 안에 잡으면 엽전 20~40냥이 쏟아집니다. 한 판의 첫 마리는 보물상자가 확정, 그 뒤로는 30%입니다. 놓치면 '뚝딱!' 하고 사라집니다. 플레이어를 다치게 하지 않고, 빛 밖에서는 금빛 기운만 보이며, 머리 위 고리와 화면 밖 화살표가 남은 시간을 알려 줍니다. 그림은 붉은 도깨비를 실행 중에 금빛으로 다시 칠해 씁니다.
- 레벨업 부적 등급: 레벨업 한 번에 등급 카드가 최대 한 장 섞입니다. 청 부적(희귀) 10%는 +2레벨, 금 부적(전설) 3%는 +3레벨에 체력을 모두 채웁니다(기획안의 15%·4%는 봇 판이 너무 쉬워져 낮춤). 선택지가 많을수록(단비 4장은 4/3배), 복주머니 레벨마다(청 +3%, 금 +1%) 잘 나옵니다. 카드는 차례로 뒤집혀 나오고, 등급 카드는 자리가 먼저 빛난 뒤 늦게 뒤집힙니다. 금이 나오면 징 소리와 함께 화면 테두리가 금빛이 됩니다. 최대 레벨을 넘는 몫은 레벨당 엽전 5냥으로 바꿉니다.
- 결산 화면: 버틴 시간 · 레벨 · 처치 · 최고 연참 · 엽전이 차례로 차오르고, 판 최고 기록을 넘은 칸에 '新' 낙관이 찍힙니다(누르면 바로 끝까지). 무기별로 준 피해와 비율을 막대로 보여 주고 1등 무기에 '이번 판의 주인'을 붙입니다. '다음 목표'에는 1탄 클리어(또는 첫 승리), 가장 싼 주막 강화, 아깝게 못 미친 처치·연참 기록을 막대로 보여 주며, 이번 판에 찬 만큼을 밝게 칠합니다. 쓰러진 문구에는 보스까지 남은 시간이나 보스의 남은 체력을 덧붙입니다.

### 보상 연출 (도파민 보강 3차)

- 호롱 터뜨리기: 빛 25를 태워 반경 6m를 쓸어 버리는 필살기입니다. 약 50초에 한 번 가득 차고(처치마다 조금씩 빨라짐), 일반 요괴는 쓰러지고 정예·보스는 최대 체력의 8%를 잃습니다. 터질 때 0.12초 멈춤과 0.45초 슬로 모션이 들어가고, 반경 안의 혼구슬은 바로 빨려 들어옵니다. 기본은 자동입니다. 가득 찼고 빛이 25 이상이며 반경 안에 요괴가 12마리 이상이거나 정예·보스가 있으면 1초 예고(법진·'호롱이 달아오른다!') 뒤 저절로 터집니다. Space나 오른쪽 아래 버튼으로 바로 터뜨릴 수 있고, 일시정지 화면에서 '직접'으로 바꾸면 저절로 터지지 않습니다.
- 업적 12개: 이루는 순간 오른쪽 위에 한지 쪽지가 뜨고, 엽전을 받거나 주막에 새 강화가 열립니다. 첫 화면 '업적 · 요괴 도감'에서 모두 볼 수 있습니다.
- 주막 새 강화 6종(업적으로 열림): 두꺼운 갓(받는 피해 −1) · 큰 등잔(빛 반경 +5%) · 봉인 도장(봉인 +1) · 엽전 꾸러미(판 엽전 +10%) · 부적 한 장 더(다시 뽑기 +1) · 호롱 심지(터뜨리기 충전 +10%).
- 요괴 도감 19칸: 처음 쓰러뜨린 요괴는 쪽지로 알리고, 처치 수만큼 별이 찹니다(일반 50·500·3,000, 정예·보스 1·3·10, 금빛 도깨비 1·3·5). 별 셋이면 짧은 설화가 열립니다. 만나지 못한 요괴는 검은 실루엣입니다.
- 막쇠·두억: 아직 '정식판' 잠금이지만, 첫 화면에 해금 조건 진행도(1탄 클리어 최고 기록, 엽전 누적)를 보여 줍니다. 플레이하려면 방향별 걷기 그림이 필요합니다.
- 결산 화면에 '이번 판에 이룬 업적'과 호롱 터뜨리기 피해 줄이 더해졌습니다.

- 새 효과음(국악 타악기): 장구 굴림 · 딱 · 징 · 꽹과리 · 도장 · 윷 · 처치음. `raw/sfx` 의 원본을 `assets/sfx` 로 복사해 씁니다(딱은 ffmpeg로 합성).

## 렌더링 · 성능

- 세계는 별도 캔버스(`#world`)에 평면으로 그리고, 2.5D 기울기는 CSS `matrix3d`(w = 1 − b·y)로 GPU가 입힙니다. `project()` 가 같은 식으로 화면 글자·화살표 위치를 맞춥니다.
- HUD는 위 캔버스(`#game`)에 기기 해상도로, 세계는 렌더 배율 `RS`(기본 1.5, 레티나 2× 대신)로 그립니다. 프레임이 계속 21ms를 넘으면 `RS` 를 0.25씩 낮춥니다(최저 0.75).
- 바닥 타일은 세계 캔버스 배율에 맞춰 한 번만 다시 그려 두고 정수 픽셀 위치에 복사하며, 밤 어둠은 미리 그린 빛 구멍 그림과 단색 사각형으로, 원근 안개는 1픽셀 폭 그라데이션을 늘여 그립니다.
- 피해 숫자와 HUD 글자는 문자열별로 한 번 그린 그림을 복사합니다(`drawText`).
- 오디오 컨텍스트·효과음 디코딩·HUD 한글 글꼴은 타이틀 화면에서 미리 준비해, 게임을 시작하는 순간 멈추지 않습니다(`warmUp`).
- 일시정지·레벨업·보부상·안내·게임 오버 화면 뒤와 불투명한 타이틀 뒤에서는 캔버스를 다시 그리지 않습니다.
- 창 크기를 바꾸는 도중에는 스프라이트를 다시 자르지 않고, 크기 조절이 끝난 뒤 한 번만 자릅니다.
- `update()`는 하위 시스템별 함수로, 요괴 갱신은 요괴 하나 단위 함수로 나눠 두었습니다. 거대한 한 함수는 드문 분기가 실행될 때마다 최적화 코드가 통째로 버려졌습니다.
- 개발용: `HORONG.pf` 로 구간별 시간, `HORONG.rs = 1` 로 렌더 배율 고정.

## 걷기 리그

등불지기는 16방향(그린 방향 9개, 서쪽은 좌우 반전)으로 돌고, 방향마다 그림 한 장으로 걷습니다. 비어 있는 팔은 따로 떼어 어깨를 축으로 돌며, 방망이·방울·붓·부적·등불을 그 손에 쥐고 씁니다(`tools/process.py`의 `ARM` 표). `tools/process.py` 가 방향별로 발이 가장 모인 그림을 고르고, 치마 밑단과 발(연이는 갈색 짚신, 단비는 흰 버선을 색으로 구분)을 떼어 `*_body` · `*_foot` 그림을 만듭니다. 게임은 발 그림을 두 번 그려 옆모습에서는 두 발이 엇갈려 내딛고(먼 발은 조금 어둡게), 앞·뒷모습에서는 좌우 대칭으로 번갈아 들게 하며, 치마는 허리 아래를 가로 띠로 나눠 걸음에 따라 흔들고, 몸은 발이 디딜 때 내려앉습니다.
